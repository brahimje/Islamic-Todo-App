# Islamic Todo v1.0.0 - Full Localization Support

## 🎉 First Official Release

Alhamdulillah! The Islamic Todo App is now available with complete localization support.

### ✨ Features

#### 🌍 Localization
- **Complete English and Arabic support** with 400+ translated strings
- **Automatic RTL layout** for Arabic language
- **Persistent language selection** - your choice is saved
- Seamless language switching from Settings

#### 🕌 Islamic Features
- **Prayer Times**: Accurate prayer times based on your location
- **Qiyam al-Layl Tracker**: Track and plan your night prayers
- **Islamic Challenges**: 30-day challenges including Quran reading
- **Religious Task Categories**: Salah, Quran, Dhikr, Dua, Sadaqah, etc.

#### ✅ Task Management
- Create and organize tasks with priority levels
- Set recurring tasks (daily, weekly, monthly, yearly)
- Religious and general task categories
- Task completion tracking with statistics

#### 📅 Prayer Planner
- Plan your daily prayers
- Timeline view of prayer schedules
- Track Sunnah and Nafila prayers
- Add custom religious activities

#### 📊 Progress Tracking
- Weekly and monthly statistics
- Track completed tasks and prayers
- Monitor your spiritual progress
- Visual charts and analytics

### 🌍 Supported Languages
- 🇬🇧 **English**
- 🇸🇦 **Arabic** (العربية)

### 📱 Platform Support
- ✅ **Android** (API 21+ / Android 5.0+)
- ✅ **macOS** (Build from source)
- ⏳ **iOS** (Untested, requires Xcode)

### 🔧 Technical Details

**Built with:**
- Flutter 3.x
- Riverpod for state management
- Hive for local storage
- Adhan library for prayer times calculations
- Geolocator for location services
- WorkManager for background tasks

**Permissions Required:**
- 📍 Location (for accurate prayer times)
- 🔔 Notifications (for prayer and task reminders)
- 📁 Storage (for data backup/restore)

### 📖 Installation Instructions

#### Android
1. Download `islamic-todo-v1.0.0.apk` from the release assets
2. Enable "Install from Unknown Sources" in your device settings
3. Open the APK file and install
4. Grant location and notification permissions when prompted
5. Set your location and madhab in Settings
6. Start using the app!

#### macOS
1. Clone the repository
2. Run `flutter pub get`
3. Run `flutter run -d macos`
